# Pomodoro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A discreet always-on-top Pomodoro pill (top-center, draggable) that expands into an Anthropic-style card on click; 25/5 cycle, waits for a click between phases.

**Architecture:** Qt-free core (`timer`, `stats`, `settings`, `placement`, `notify`) fully unit-tested; one PySide6 frameless window (`ui/window.py`) with pill/card states animated by a single `expansion` property; `app.py` wires a 250 ms poll loop.

**Tech Stack:** Python ≥3.11, uv, PySide6 (incl. QtMultimedia), pytest.

**Spec:** `docs/superpowers/specs/2026-10-11-pomodoro-design.md`

## Global Constraints

- Palette: cream `#F5F1E8`, graphite `#1F1E1C`, clay `#CC785C` (focus), sage `#7A9A82` (break), border `#E3DCCB`.
- Fonts: Source Serif 4 (numerals), Inter (labels), bundled with OFL license files.
- Pill ~120×34, card ~300×200 logical px; pill rest opacity 0.75; expand animation ~220 ms ease-out; auto-collapse after 6 s without hover (not while awaiting).
- Default position: centered on primary screen, `top = availableGeometry.top + 12`.
- Window flags: `Tool | FramelessWindowHint | WindowStaysOnTopHint`, `WA_ShowWithoutActivating`, `WA_TranslucentBackground`.
- Data: `~/.config/pomodoro/settings.json`, `~/.local/share/pomodoro/history.json` (respect `XDG_CONFIG_HOME` / `XDG_DATA_HOME`).
- Code/comments English; UI strings + README pt-BR; license MIT.

## Review Focus

1. Laptop suspended mid-phase → on wake the elapsed sleep time counts (use `CLOCK_BOOTTIME`), phase ends once with chime.
2. Phase ends while paused-then-resumed or while the card is open → exactly one phase-end event.
3. Focus phase completes after midnight → counted under the date it completed.
4. Screen resolution/monitor changes so saved position is off-screen → fall back to default.
5. App launched twice (autostart + menu) → second launch expands the running one and exits.

### Task 1: Project scaffold + timer state machine

**Files:** Create `pyproject.toml` (via `uv init --package`), `src/pomodoro/__init__.py`, `src/pomodoro/timer.py`, `tests/test_timer.py`.

**Interfaces — Produces:**
- `class Phase(StrEnum)`: `IDLE, FOCUS, AWAITING_BREAK, BREAK, AWAITING_FOCUS`.
- `@dataclass(frozen=True) class PhaseEnded: phase: Phase; seconds: float` (phase ∈ {FOCUS, BREAK}).
- `def boottime() -> float` (`time.clock_gettime(time.CLOCK_BOOTTIME)`).
- `class Timer(focus_seconds: float, break_seconds: float, clock: Callable[[], float] = boottime)` with attributes `phase`, `paused`; methods `start()`, `pause()`, `resume()`, `toggle_pause()`, `restart_phase()`, `skip()`, `reset()` (→ IDLE), `remaining() -> float`, `duration() -> float`, `progress() -> float` (0..1 elapsed), `poll() -> PhaseEnded | None`.
- Semantics: `start()` valid from IDLE/AWAITING_FOCUS → FOCUS, AWAITING_BREAK → BREAK; no-op otherwise. `skip()` FOCUS→AWAITING_BREAK, BREAK→AWAITING_FOCUS, returns nothing, no event. `poll()` when remaining ≤ 0 moves to the AWAITING_* state and returns the event once. In IDLE/AWAITING_* `remaining()` = duration of the next phase, `progress()` = 0.

- [ ] Step 2: Tests (fake clock `t=[0.0]; clock=lambda: t[0]`): `test_full_cycle` (start → advance 1500 → poll returns `PhaseEnded(FOCUS,1500)` → phase AWAITING_BREAK → second poll None → start → BREAK → advance 300 → AWAITING_FOCUS); `test_pause_freezes_remaining` (advance 100, pause, advance 1000, remaining == 1400, resume, advance 1400 → event); `test_skip_no_event`; `test_restart_phase` (advance 600, restart → remaining 1500); `test_poll_once_after_long_gap` (advance 10_000 → exactly one event, phase AWAITING_BREAK); `test_start_noop_while_running`.

### Task 5: Window (pill ↔ card)

**Files:** `src/pomodoro/ui/__init__.py`, `src/pomodoro/ui/theme.py`, `src/pomodoro/ui/window.py`, `tests/test_window_smoke.py`.

**Interfaces:**
- Consumes: `Timer`, `Phase`, `Stats`, `placement.*`.
- Produces: `class PomodoroWindow(QWidget)` with signals `start_requested`, `toggle_requested`, `restart_requested`, `skip_requested`, `quit_requested`, `moved(QPoint)`; methods `set_state(phase: Phase, paused: bool, remaining: float, progress: float, today_count: int, today_minutes: int)`, `expand(auto: bool = False)`, `collapse()`, `place(pos: tuple[int,int])`, property `expansion: float` (0 pill … 1 card, animated by `QPropertyAnimation`, `OutCubic`, 220 ms).
- `theme.py`: colors, `load_fonts() -> tuple[str, str]` (serif family, sans family via `QFontDatabase.addApplicationFont`, fallback to "Serif"/"Sans").

Behaviour (paint everything with QPainter; window keeps a transparent margin for the shadow):
- Pill: progress dot (ring) in phase color, `MM:SS` in serif; idle text `Pomodoro ▸`; AWAITING_* → pulsing (sine on alpha, period 2 s) in next-phase color + text `Descanso ▸` / `Foco ▸`. Opacity 0.75 → 1.0 on hover.
- Card: ring (stroke 6) with serif time 34 pt; label `Foco` / `Descanso` / `Pronto para focar`; AWAITING → title `Hora do descanso` / `Hora de focar` + **Começar** button; bottom row: icon buttons ⟲ (restart) ▶/❚❚ (toggle) ⏭ (skip) and today's dots (max 8 drawn, then `+N`) + `N min`.
- Click pill → `expand()` + `activateWindow()`. Space/Esc while active. Collapse on deactivate (if activated), Esc, or 6 s no-hover (not in AWAITING).
- Drag only from the pill state; after a drag > 4 px no click is fired; emit `moved`.
- Right-click → `QMenu` with `Voltar ao topo` and `Sair`.
- Card geometry from `placement.card_geometry` so it grows downward from the pill.
